# Current stage: PLAN

## Task

Based on the probe findings, present the teaching plan (3-6 items). **This stage presents the plan only — do not start teaching.**

## The plan must include

1. **Which unconditional truths to establish first**: 2-3 rock-solid facts the learner can accept with no caveats (first principles or clean definitions). The foundation.
2. **The build order**: path from foundation to target concept, each step answering one "why".
3. **Which misconception to dislodge first** (if probing found one).

Be concrete. Write "first confirm you accept A and B, then derive C from A+B" — not "let's learn about X".

## Stage exit

After presenting the plan, write on its own final line:
